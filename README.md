# 🗄️ SQL Tasks & Practice

A collection of **SQL practice programs, database exercises, and hands-on tasks** created while learning and strengthening SQL and DBMS concepts.

This repository contains practical SQL scripts covering everything from **basic database operations to joins, aggregate functions, grouping, constraints, and relational database concepts**.

---

## 📌 About the Repository

This repository is maintained as a learning and practice workspace for SQL.

The goal is to build a strong understanding of how relational databases work by writing and executing SQL queries on different sample databases and datasets.

The exercises include examples based on:

* 👨‍💼 Employee Management
* 🏥 Hospital Management
* 🎓 College / Student Management
* 🛒 Sales & Products
* 🏢 Departments
* 📊 Data Analysis using SQL

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Pratik-Pattewar1/Sql_Tasks.git
```

### 2. Open the project

```bash
cd Sql_Tasks
```

### 3. Open the SQL files

You can use any MySQL-compatible SQL environment, such as:

* MySQL Workbench
* MySQL Command Line Client
* VS Code with a MySQL extension
* Other MySQL database tools

### 4. Execute the scripts

Run the SQL files individually according to the topic or task you want to practice.

For example:

```sql
SOURCE Sql_basics.sql;
```

Or open the file directly in MySQL Workbench and execute the required queries.

> ⚠️ Some scripts create databases and tables with specific names. Make sure you understand the commands before executing them in an existing database environment.
